Boundaries: geoBoundaries (geoboundaries.org), ADM1, representing 2017, from OpenStreetMap / Wambacher — Open Data Commons ODbL 1.0.
Region & city statistics: Wikidata, queried live over SPARQL — CC0 1.0. Country facts: REST Countries v5.
The two sources name regions differently ("Region of Trenčín" vs "Trenčín Region"), so they are joined on a normalised key — the same match_key the MCP server returns.
Note for maintainers: geoBoundaries GeoJSON lives in Git LFS, and only media.githubusercontent.com serves it to a browser. raw.githubusercontent.com returns a 131-byte LFS pointer file, and the github.com/…/raw/… URL the API publishes 302-redirects with an empty access-control-allow-origin, which fails the browser CORS check on the redirect hop. Either way the map renders blank. Also: serve this page over http, not file://.
