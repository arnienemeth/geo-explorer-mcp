Boundaries: geoBoundaries ADM1 (licence loading…). Statistics: Wikidata, queried live over SPARQL — CC0 1.0. Flags: REST Countries flag CDN.
The two sources name regions differently — geoBoundaries says Bayern where Wikidata's English label is Bavaria — so they are joined on a normalised key computed from every name variant, native names included. That is the same match_keys the MCP server returns.
Notes: geoBoundaries GeoJSON lives in Git LFS and only media.githubusercontent.com serves it to a browser — raw.githubusercontent.com returns a 131-byte pointer file, and the github.com/…/raw/… URL 302-redirects with an empty access-control-allow-origin, failing the CORS check on the redirect hop. Serve this page over http, not file://. ISO 3166-2 mixes administrative levels in some countries (the UK lists 252 subdivisions where geoBoundaries ADM1 has 4), so only regions with a matching boundary are shown.
